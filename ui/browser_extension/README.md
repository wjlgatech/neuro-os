# Founder Loop — browser extension

Manifest V3 extension. Companion to the `founder_loop` engine in
`agent/founder_loop/`. Renders the **Tank widget** and the
**Sublimation Card** at the moment of urge.

## What it does

1. **Badge** — every 5 minutes, polls `http://127.0.0.1:8765/tank` and
   updates the action icon's badge with the current tank percent.
2. **New tab** — replaces Chrome's new-tab page with a dashboard:
   greeting, tank, today's priorities, last few ticks, and the live
   diagnosis (if any).
3. **Popup** — clicking the action icon shows the same content in a
   compact form.
4. **Content overlay** — when you navigate to a high-distraction site
   (YouTube, Twitter/X, Reddit, HN, Instagram, TikTok, Facebook), the
   extension calls `/tick` and, if the loop diagnoses an underlying
   need, mounts the Sublimation Card. The card is *always*
   dismissable; "proceed anyway" is *always* visible. Honors agency.

The extension never blocks navigation. It surfaces yesterday-self's
contract and the constructive-expression options. Override is logged
(POST `/events { kind: overrode_proposal }`), tank debits per the
contract's abuse-tax.

## Install (Chrome / Chromium / Edge)

1. Build the daemon's runtime data (see top-level `README.md` for the
   `loop morning` step).
2. Start the daemon:

   ```bash
   python -m agent loop serve \
     --registry users/me/registry.jsonl \
     --contracts users/me/contracts.jsonl \
     --workflowx-fixture path/to/exports.jsonl \
     --port 8765
   ```

3. Open `chrome://extensions/`, toggle **Developer mode**, click
   **Load unpacked**, and select this directory
   (`ui/browser_extension/`).
4. Pin the extension. The badge should show the current tank percent.

## Install (Firefox)

Manifest V3 is supported in Firefox 109+. Use `about:debugging` →
**This Firefox** → **Load Temporary Add-on** → select
`ui/browser_extension/manifest.json`.

## Settings

Click the popup's ⚙ icon to change the daemon URL. Stored in
`chrome.storage.local`. Default `http://127.0.0.1:8765`.

## File map

```
manifest.json   # Manifest V3 declaration
background.js   # service worker; alarm-driven badge updates
content.js     # injected on distraction hosts; mounts Sublimation Card
overlay.css    # styles for the injected card
popup.{html,js,css}    # action-icon popup
newtab.{html,js,css}   # new-tab page
lib/api.js     # daemon client (shared)
lib/card.js    # render functions for Tank widget and Sublimation Card
icons/         # generated by icons/generate.py
```

The two `lib/*.js` files set globals (`FounderLoopAPI`,
`FounderLoopUI`) so the same render code runs in popup, newtab, and
content-script contexts without a module loader.

## Privacy

The extension only fetches `http://127.0.0.1:8765`. The daemon refuses
to bind to non-loopback hosts (see
`agent/founder_loop/server.py::serve`). No data leaves your machine.
