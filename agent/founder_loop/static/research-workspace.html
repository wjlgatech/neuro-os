1. Ingest checking key…

Drop a folder, paste a URL, or paste raw text. Each source becomes one or more MechanismCardProposal rows in your review queue. With an Anthropic key, an LLM extracts mechanism / invariant / prediction / failure mode per source. Without a key, a regex heuristic produces low-confidence drafts you can still review.
Absolute path to a directory of .txt / .md / .pdf files. Each file becomes one source. Example: /Users/you/Documents/papers — equivalent to neuro-os research ingest --prefer local --source-dir <path>.
Paste any URL — .pdf, .md, or any HTML page. Trafilatura strips boilerplate and extracts clean markdown. Enable Follow links to also crawl same-domain sub-pages up to depth hops (default 1 = seed + all links on that page). Full pipeline auto-accepts all proposals and compresses immediately — no review step.
For quick capture — paste an abstract, a tweet thread, or your own notes. We treat it as one source. Give it a one-line title in the first field so it can be cited later.

2. Review proposals

Each proposal is a draft MechanismCard. Accept the ones that pass your bar; reject the rest. Acceptance writes a card to disk — that's the input to compression in step 3.
Open review queue →

3. Compress

Roll accepted cards into a 3-level hierarchy: ≤5 cores (L0), ≤30 sub-mechanisms (L1), all cards (L2). First we run a synthesis pass that clusters cards by overlap, then we group clusters into the L0 cores. Equivalent to: neuro-os research synthesize → neuro-os research compress.

    4. Express & reveal

    Re-render a compressed principle in a different modality (visual, musical, physical, organizational, game, biological, narrative). The point isn't art — it's stress-testing: if a principle survives translation to a new shape, it's structurally sound. If translation breaks, the principle has a hidden assumption. After expressing, reveal what the new modality showed you.
